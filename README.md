- Project folders: `articles/`, `evidences/`, `kashmir-lockdown-situation/`, `notes/`.

## Using Git and GitHub

If you have a GitHub account and want to work with this repository using Git:

1. Install Git (Linux example):

```bash
sudo apt update && sudo apt install git -y
```

2. Clone the repository (replace the URL with the repository you want):

```bash
git clone https://github.com/rise-of-hope/kashmir-massacre.git
cd kashmir-massacre
```

3. Common Git commands:

```bash
git status           # show changed files
git add .            # stage changes
git commit -m "msg" # commit staged changes
git pull             # fetch and merge remote changes
git push             # push commits to remote
```

If you plan to push changes you must configure Git with your name and email:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

If the remote repository requires authentication, follow GitHub's instructions to set up HTTPS or SSH authentication and connect your local Git client to your GitHub account.

## If You Do NOT Have a GitHub Account — Download ZIP

You can download the entire repository as a ZIP file from the GitHub website without signing in:

1. Open the repository page in your web browser (example):

   - https://github.com/rise-of-hope/kashmir-massacre

2. Click the green **Code** button, then choose **Download ZIP**.

3. After downloading, unzip the file on your computer. On Linux:

```bash
unzip /path/to/kashmir-massacre-main.zip -d /path/to/destination
```

You can also download the ZIP from the command line (replace `main` if the repository uses `master`):

```bash
wget https://github.com/rise-of-hope/kashmir-massacre/archive/refs/heads/main.zip -O kashmir-massacre-main.zip
unzip kashmir-massacre-main.zip
```
